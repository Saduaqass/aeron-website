# AERON

AERON — Premium Interactive 3D Electric Vehicle Website. An independent digital experience for a fictional premium electric vehicle concept brand.

## Project status

Initial repository structure. Website implementation is in progress.

## Planned stack

Next.js App Router, React, TypeScript, Tailwind CSS, Three.js with React Three Fiber and Drei, Motion for React, Lucide icons.

## Development

Prerequisite: Node.js LTS and npm.

```bash
npm install
npm run dev
```

## Structure

- `src/app` — routes and app shell
- `src/components` — layout, UI, sections, and 3D components
- `src/hooks`, `src/lib`, `src/locales`, `src/styles`, `src/types` — shared app code
- `public` — models, images, textures, and icons
- `tests` — browser and component checks

## Design and implementation skills

Reviewed and applied instructions from the installed `emilkowalski/skills` collection: `emil-design-eng`, `animate`, `choreograph`, `gestures`, `animation-performance`, `apple-design`, and `mobile-native`. The collection recommends `npx skills@latest add emilkowalski/skills`; its README and available `SKILL.md` inventory were reviewed before implementation. Frontend structure and accessibility practices also follow the installed `frontend-engineer` skill.

## 3D assets and licensing

The vehicle is an original procedural concept model built for this project. No third-party vehicle model has been added. Any future external assets will be documented here with their license and source.
